## Raisons

- `docker compose down` libère les ports (8000, 8080, 8025, 3306) et la mémoire, tout en gardant le volume `instruments_de_musique_database_data`.
- Le README distingue `stop` (pause), `down` (arrêt, données conservées) et `down -v` (suppression de la base), pour éviter une perte de données par erreur.

## Commandes lancées

    docker compose down     # php, database, phpmyadmin, mailer et réseau supprimés
    docker compose ps       # aucun conteneur
    docker volume ls        # volume instruments_de_musique_database_data conservé
