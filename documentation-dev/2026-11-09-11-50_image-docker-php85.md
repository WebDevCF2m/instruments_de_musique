## Raisons

- Le projet tourne entièrement sous Docker : PHP 8.5, MariaDB, PHPMyAdmin, Mailpit.
- `FallbackResource /index.php` envoie toutes les URL vers Symfony, sans installer `symfony/apache-pack`.
- `www-data` prend l'UID 1000 (utilisateur WSL `formaweb`) pour éviter les problèmes de droits sur `var/`.
- Dans le conteneur, `DATABASE_URL` et `MAILER_DSN` sont surchargés pour viser les services `database` et `mailer` ; le `.env` (`127.0.0.1:3306`) reste valable pour les commandes lancées depuis WSL.
- OPcache n'est pas installé à part : il est intégré à PHP 8.5.
